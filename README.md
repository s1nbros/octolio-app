# Octolio — Financial Literacy App

Duolingo-style gamified financial education. Learn budgeting, saving, investing and credit — in **English** or **Bulgarian**.

## Quick Start

```bash
# Install all dependencies
npm run install:all

# Start both servers (frontend + backend)
npm run dev
```

- **Frontend:** http://localhost:5173
- **Backend:** http://localhost:3001

## Tech Stack

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Backend:** Node.js + Express + TypeScript
- **Database:** SQLite (auto-created on first run)
- **Auth:** JWT

## Features

- 4 modules · 12 lessons · 48+ exercises
- XP, levels, streaks, hearts/lives system
- Full English / Bulgarian language switch
- Dark glassmorphism UI matching Octolio brand colors
- Progress saved per account
